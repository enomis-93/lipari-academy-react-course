Esempio funzionante, minimo e coerente con le versioni del corso (React 19, Vite 8, React Router 7).

Ogni comando o snippet da copiare sta in un blocco con il linguaggio indicato, un obiettivo per blocco. Prima del blocco indica **dove** eseguire il comando o **quale file** modificare.

Per verificare la versione di Node.js, dentro la cartella `liparibank/`, esegui:

```bash
node --version
```

Crea il file `src/components/Example.jsx`. Il percorso si ripete nel `title` del blocco, così compare nella barra del codice:

