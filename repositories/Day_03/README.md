# LipariBank — checkpoint Day 3

Stato del progetto alla fine del **Day 3 — State & Events** del corso *React Zero to Hero*.

La dashboard interattiva: selezione del conto, mostra/nascondi saldi, filtri per tipo, ricerca testuale e movimenti preferiti, con tutto lo state in `Dashboard`.

> Progetto didattico: tutti i dati sono fittizi e nessuna operazione bancaria è reale.

## Avvio

Serve Node.js 22 LTS (22.12 o successivo). Dentro questa cartella:

```bash
npm install
```

```bash
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale (di solito `http://localhost:5173/`).

## Controlli

`npm run lint` e `npm run build` devono terminare senza errori.
