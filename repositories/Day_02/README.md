# LipariBank — checkpoint Day 2

Stato del progetto alla fine del **Day 2 — Components & Props** del corso *React Zero to Hero*.

La dashboard costruita con componenti riutilizzabili: `Dashboard` come container, `Card`, card dei conti, lista dei movimenti con stato vuoto e sezioni "Movimenti" per conto.

> Progetto didattico: tutti i dati sono fittizi e nessuna operazione bancaria è reale.

## Avvio

Serve Node.js 22 LTS (22.12 o successivo). Dentro questa cartella:

```bash
npm install
```

```bash
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale (di solito `http://localhost:5173/`).

## Controlli

`npm run lint` e `npm run build` devono terminare senza errori.
