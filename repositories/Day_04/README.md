# LipariBank — checkpoint Day 4

Stato del progetto alla fine del **Day 4 — Forms & User Input** del corso *React Zero to Hero*.

Il form del bonifico simulato: campi controllati, validazione con messaggi accessibili, gestione del focus con `useRef`, nuovo movimento in elenco e saldi ricalcolati come dati derivati.

> Progetto didattico: tutti i dati sono fittizi e nessuna operazione bancaria è reale.

## Avvio

Serve Node.js 22 LTS (22.12 o successivo). Dentro questa cartella:

```bash
npm install
```

```bash
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale (di solito `http://localhost:5173/`).

## Controlli

`npm run lint` e `npm run build` devono terminare senza errori.
