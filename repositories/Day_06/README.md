# LipariBank — checkpoint Day 6

Stato del progetto alla fine del **Day 6 — Routing** del corso *React Zero to Hero*.

LipariBank a più pagine con React Router 7: Dashboard, Conti con dettaglio in route annidate, Movimenti, Bonifico e pagina 404, con lo state condiviso in `App.jsx`.

> Progetto didattico: tutti i dati sono fittizi e nessuna operazione bancaria è reale.

## Avvio

Serve Node.js 22 LTS (22.12 o successivo). Dentro questa cartella:

```bash
npm install
```

```bash
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale (di solito `http://localhost:5173/`).

## Controlli

`npm run lint` e `npm run build` devono terminare senza errori.
