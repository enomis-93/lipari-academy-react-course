# LipariBank — checkpoint Day 1

Stato del progetto alla fine del **Day 1 — React Fundamentals** del corso *React Zero to Hero*.

La prima dashboard statica: intestazione con il cliente, saldo totale e ultimi cinque movimenti, letti da `src/data/mockData.js`.

> Progetto didattico: tutti i dati sono fittizi e nessuna operazione bancaria è reale.

## Avvio

Serve Node.js 22 LTS (22.12 o successivo). Dentro questa cartella:

```bash
npm install
```

```bash
npm run dev
```

Poi apri l'indirizzo mostrato dal terminale (di solito `http://localhost:5173/`).

## Controlli

`npm run lint` e `npm run build` devono terminare senza errori.
